## Safe integration
1. Create a feature branch in the existing repository.
2. Inspect existing files before copying: **do not blindly overwrite work**.
3. Copy the folders and files from this ZIP into the repository root.
4. Add links to the five docs in the repository's **existing** `README.md` (this package intentionally does not replace it).
5. Run `python3 scripts/hello_python.py` (or `py scripts/hello_python.py` on Windows).
6. Review formatting and links, commit, push, open PR, run CI, and merge after review.
