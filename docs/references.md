# Research References

**Prepared by Emmanuel | Python Launchpad**

These official references support the installation, execution, environment, and packaging instructions. Always verify the steps against the operating system and Python release used during recording.

1. Python Software Foundation — [Python documentation](https://docs.python.org/3/): language and standard library.
2. Python Software Foundation — [Python downloads](https://www.python.org/downloads/): official installers.
3. Python Software Foundation — [Python tutorial](https://docs.python.org/3/tutorial/): introductory concepts.
4. Python Software Foundation — [Using Python on Windows](https://docs.python.org/3/using/windows.html): Windows installation and command options.
5. Python Software Foundation — [Using Python on macOS](https://docs.python.org/3/using/mac.html): macOS installation.
6. Python Software Foundation — [Using Python on Unix](https://docs.python.org/3/using/unix.html): Unix/Linux usage.
7. Python Software Foundation — [venv](https://docs.python.org/3/library/venv.html): virtual environments.
8. Python Software Foundation — [ensurepip](https://docs.python.org/3/library/ensurepip.html): pip bootstrapping.
9. Python Packaging Authority — [Python Packaging User Guide](https://packaging.python.org/en/latest/): pip, dependencies, and environments.
10. Python Package Index — [PyPI](https://pypi.org/): package index.
11. Python Software Foundation — [dis module](https://docs.python.org/3/library/dis.html): CPython bytecode documentation.
12. Python Software Foundation — [IDLE](https://docs.python.org/3/library/idle.html): beginner environment.
13. Microsoft — [VS Code Python](https://code.visualstudio.com/docs/languages/python): Python extension and interpreter selection.
14. JetBrains — [PyCharm documentation](https://www.jetbrains.com/help/pycharm/quick-start-guide.html): Python project workflow.
